# 🎓 E-Learning Platform Purchase Analysis using MySQL
 
> 📊 Module Capstone Project focused on analyzing learner purchases, course performance, sales trends, and revenue generation using MySQL.
 
---
 
## 📌 Project Overview
 
This project analyzes purchase data from an E-Learning platform using MySQL. The objective is to gain insights into learner enrollments, course popularity, purchasing behavior, and revenue generation through SQL queries and database objects.
 
---
 
## 🎯 Objectives
 
- Design a relational database for an E-Learning platform.
- Store learner, course, and purchase information.
- Analyze purchase trends and learner behavior.
- Generate business insights using SQL.
- Implement joins, views, stored procedures, triggers, and user-defined functions.
 
---
 
## 🗂️ Database Schema
 
### Learners
- learner_id
- full_name
- country
 
### Courses
- course_id
- course_name
- category
- unit_price
 
### Purchases
- purchase_id
- learner_id
- course_id
- quantity
- purchase_date
